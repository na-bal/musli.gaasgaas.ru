# musli.gaasgaas.ru

Страница-карточка Мюслей для Telegram. Робот Telegram не достаёт до хостинга
gaasgaas.ru, поэтому заголовок и картинку для превью отдаёт этот сайт
(GitHub Pages), а человека он сразу переправляет на https://gaasgaas.ru/musli/.

Руками не править: файлы собирает `scripts/tg-card.py` в репозитории сайта.
